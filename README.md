# Armoury: Grey Knights

**Status: Concept / Planning**

Armoury: Grey Knights is an exploratory project for a possible future *Warhammer 40,000: Rogue Trader* armoury mod focused on Grey Knight weapons.

This repository is for research, planning, and early design work. Its existence does **not** represent a commitment that the mod will be completed. No weapons are implemented at this stage.

## Possible future integration

This project may later integrate with **Origin: Grey Knight**.

Any such integration, along with the scope and technical approach of the mod, remains undecided.

## Project structure

- `docs/` — planning notes and design documentation
- `src/` — reserved for possible future implementation

## Current scope

- Track candidate weapons and implementation considerations.
- Investigate technical feasibility.
- Avoid gameplay implementation until the project moves beyond the concept/planning stage.
